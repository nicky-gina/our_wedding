# V3.8.1 — Moon Stability Fix

## Root cause
V3.8 still rendered the moon PNG through a CSS `::after` pseudo-element with two `drop-shadow()` filters. On some first loads, the browser briefly composited the filtered layer as a pale opaque rectangle.

## Fix
- The moon is now rendered as a real `<img>` element in both the landing screen and ambient world.
- The moon PNG is preloaded with high priority.
- All pseudo-element moon images and filters are disabled by a final authoritative CSS block.
- No other V3.8 feature or content was changed.
