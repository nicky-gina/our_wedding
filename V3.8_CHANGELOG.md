# V3.8 — Visual Polish

Built from Editorial Invitation V3.7.

## Included
- Improved text readability against bright moon and sky areas using localized dark veils, refined colors, and subtle text shadows.
- Premium typography refinements: optical sizing, kerning, ligatures, balanced headings, improved paragraph rhythm, and tabular date numerals.
- Cinematic section reveals using controlled blur, scale, vertical movement, image masking, and staggered timing.
- Subtle multi-layer celestial depth driven through a single CSS variable and requestAnimationFrame scroll updates.
- Refined active-scene frame lighting without changing the moon artwork.
- Reduced-motion safeguards for all new visual effects.

## Not included yet
- Storytelling enhancements (animated timeline, chapter progress upgrades, scroll narrative), reserved for V3.9.
- Dynamic moon lighting remains intentionally restrained to avoid readability and rendering regressions.
