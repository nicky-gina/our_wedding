# V3.9.1 — Cinematic Interludes

Built from the re-uploaded V3.9 storytelling baseline.

## Added
- Four distinct cinematic interlude variants: celestial curtain, timeline opening, upward light reveal, and invitation-page opening.
- Interludes now animate in while visible and softly close/fade when leaving the viewport.
- All motion uses only transform and opacity.
- Mobile travel distances are reduced for compositor stability.
- Reduced-motion mode presents the content immediately without animation.

- `index.html`
- `css/styles.css`
- `js/app.js`
