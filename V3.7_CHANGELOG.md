# V3.7 Changelog

## Accessibility and multilingual support

- Three languages: English, Bahasa Indonesia, and Simplified Chinese.
- First-visit browser-language detection with remembered manual preference.
- Language selector integrated into the top navigation.
- Translated dynamic personalized greeting, RSVP feedback, deadlines, guestbook pagination, and gallery captions.
- Updated document language and chapter labels when switching languages.
- Added skip navigation, visible keyboard focus, screen-reader live regions, and improved dialog/form semantics.
- Parent-information blocks remain intentionally bilingual in every language.
