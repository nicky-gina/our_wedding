# Code structure

## Runtime files

- `index.html` — semantic page and scene markup.
- `css/styles.css` — all visual styles, responsive rules and animation definitions.
- `js/config.js` — editable project settings and service endpoints.
- `js/app.js` — opening sequence, celestial world, scenes, countdown, gallery, RSVP and guestbook behaviour.
- `backend/Code.gs` — optional Google Apps Script backend.

## Editing rule

Keep configuration values in `config.js`. Add visual changes to the relevant commented section in `styles.css`, and behavioural changes to the relevant commented section in `app.js`.
